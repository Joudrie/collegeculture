# College Culture

Casual, honest snapshots of New England colleges for high schoolers. Not rankings, not advice. See README.md for how the site is built and how to add a school.

## Workflow

- Always merge finished work into `main` and push it. No exceptions; the owner asked for this. Work on a branch if useful, then merge to `main` (fast-forward or merge commit) and push `main` in the same turn.
- Before merging, run `node tools/check-schools.js` and make sure every school passes.

## Content rules

- Write like you're telling a 16-year-old the truth: short, direct, no brochure language, no em-dashes, no emoji.
- Stereotypes are framed as what people say, with an honest verdict. Never insult specific people, and never use race, religion, gender or sexuality as a stereotype.
- Don't invent facts. Keep uncertain claims general.

## Design rules

Follow the design rules in README.md. Avoid "vibe coded" tells: no purple gradients, sparkles, emoji as UI, hover animations, fake testimonials, mixed border radiuses, off-grid spacing or non-working links.
