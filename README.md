# College Culture

What colleges are actually like, written for high schoolers. Not rankings and not advice. Each school page covers the vibe, social life, getting in, stereotypes vs. reality, myths, and who it's a good fit for, based on what students and alumni say.

## Prototype

`prototype/northeastern.html` is the first sample school page. Open it in a browser; it's a single file with no build step.

How a school page is built:

- **School colors.** The header band uses three values per school: the band color, the text color on it, and an accent. Northeastern is black and white with red.
- **One font.** Archivo, condensed for the school name and section titles, normal width for reading.
- **Collapsible sections.** A one-screen summary up top, then sections that open on tap, each with a one-line preview.
- **Strict system.** Text sizes 13 / 15 / 17 plus the display size, spacing on an 8pt scale, one 4px radius, no decorative animation.

Content on the sample page is approximate as of 2026 and should be checked before anything goes public.
